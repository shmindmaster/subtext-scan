# subtext-scan

Library and CLI that finds text a model can read and a person cannot see
in PDF, DOCX, and HTML, and flags prompt-injection phrasing. Source is
`src/` and `bin/subtext-scan.mjs`. There is no application server.

## Commands

```text
docker compose run --build --rm test
docker compose run --rm typecheck
```

Node 22. Dependencies stay in the image. Do not create `node_modules` in
the checkout.

## Rules

- A finding needs a page, a reason, and a severity. Do not flag visible
  quoted attacks at the default `--fail-on high` gate.
- The scanner makes no network calls and needs no API key.
- Fixtures in `fixtures/` are generated by `scripts/generate-fixtures.mjs`.
  Regenerate inside the container. Do not hand-edit a binary fixture.
- The root `AGENTS.md` applies in every directory. `src/AGENTS.md` and
  `tests/AGENTS.md` add the local commands.
