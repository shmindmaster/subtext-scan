# Code of conduct

We want participation in subtext-scan to be useful, respectful and safe. Welcome behaviour includes:

- giving specific technical feedback
- testing claims
- crediting others
- accepting correction
- making room for people with different experience levels and backgrounds

Harassment, personal attacks, discriminatory language, unwanted sexual attention and publishing someone's private information are not acceptable. The same goes for sharing real documents or personal data in issues or fixtures.

To report a concern, contact the maintainer privately through the email on the maintainer's GitHub profile. Reports are handled confidentially. The maintainer may edit or remove contributions, or restrict participation, to keep the project safe.
